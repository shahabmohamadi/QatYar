# قطعه‌یار — مدیریت فروشگاه قطعات موبایل

سامانهٔ فارسی برای یک رایانهٔ ویندوزی مرکزی و دسترسی کارکنان از مرورگر شبکه. مبلغ‌های عملیاتی به‌صورت عدد صحیح **ریال** ذخیره می‌شوند و در رابط با جداکنندهٔ هزارگان دیده می‌شوند. پایگاه دادهٔ SQLite هنگام نصب ساخته می‌شود.

## امکانات

- کالا، کد/SKU، جستجوی نام و کد، چند سطح قیمت، موجودی و سابقهٔ تغییرات.
- خرید، فروش، برگشت، ثبت دریافت و پرداخت در حساب صندوق یا بانک انتخابی.
- مشتریان و تأمین‌کنندگان، چک‌ها، درآمد و هزینه، گزارش سود و زیان با بازهٔ تاریخ.
- بخش‌های جداگانهٔ تنظیمات برای نام و لوگو، قیمت، حساب‌ها، امنیت، بکاپ و به‌روزرسانی.
- بکاپ روزانه و دستی، بازگردانی روی رایانهٔ جدید و اجرای خودکار برنامه پس از روشن‌شدن ویندوز.
- آرشیو فقط‌خواندنی پارسیان برای نصب‌هایی که دادهٔ قبلی را از بکاپ خودشان منتقل کرده‌اند.

**این مخزن فقط کد و ساختار داده را دارد. هیچ موجودی، فاکتور، چک، کاربر، رمز یا دیتابیس فروشگاه در آن نیست.** نصب تازه با پایگاه دادهٔ خالی شروع می‌شود. برای ادامهٔ کار با دادهٔ موجود، بکاپ گرفته‌شده از نصب قبلی را بازگردانی کنید.

## نصب از GitHub روی ویندوز

از صفحهٔ مخزن، نسخهٔ منبع را با `Code → Download ZIP` بگیرید و از حالت فشرده خارج کنید. در پوشهٔ پروژه، PowerShell را با **Run as administrator** باز کنید و اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\install.ps1
```

نصاب Python 3.12 را از فایل آفلاین همراه بسته، یا در صورت نبود آن از `winget`، آماده می‌کند؛ سپس وابستگی‌ها را از بسته‌های آفلاین یا `pip` می‌گیرد. نصب اینترنتی به اتصال ویندوز به اینترنت نیاز دارد. در اولین نصب، رمز مالک را در همان پنجره تعیین می‌کنید. داده در `C:\ProgramData\MobilePartsShop` و کد در `C:\Program Files\MobilePartsShop` قرار می‌گیرد.

برنامه روی `http://localhost:8080` اجرا می‌شود؛ از دستگاه‌های دیگر شبکه با `http://IP-WINDOWS:8080` باز می‌شود. سرویس در بوت ویندوز بالا می‌آید و میانبر برای همهٔ کاربران در Start Menu، دسکتاپ عمومی و Startup ساخته می‌شود.

## بکاپ و انتقال داده

در پنل مالک، «تنظیمات ← بکاپ» را باز کنید. بکاپ خودکار هر روز ساعت ۲ اجرا می‌شود؛ مسیر پیش‌فرض `C:\ProgramData\MobilePartsShop\backups` است. برای جابجایی، برنامه را روی ویندوز جدید نصب و بکاپ نصب قبلی را با دستور زیر بازگردانی کنید:

```powershell
powershell -ExecutionPolicy Bypass -File 'C:\Program Files\MobilePartsShop\windows\restore.ps1' -BackupFile 'D:\transfer\store-backup.zip'
```

ابزار بازگردانی، برنامه را موقتاً متوقف می‌کند و سلامت فایل بکاپ را بررسی می‌کند. کاربران و رمزهای ذخیره‌شده در بکاپ همراه داده منتقل می‌شوند.

## به‌روزرسانی از GitHub

مالک در «تنظیمات ← به‌روزرسانی» نام مخزن را به شکل `owner/repo` ثبت و نسخهٔ جدید را بررسی می‌کند. متن تغییرات Release پیش از دکمهٔ اعمال نمایش داده می‌شود. انتشار باید یک فایل `QatYar-Windows.zip` با اثرانگشت SHA256 در GitHub Releases داشته باشد. نصب خودکار پیش از تغییر کد و دیتابیس بکاپ می‌گیرد. برای مخزن خصوصی، توکن خواندن Release باید فقط روی ویندوز مرکزی در `C:\ProgramData\MobilePartsShop\github-token.txt` با دسترسی محدود به Administrators و SYSTEM قرار گیرد؛ توکن از فرم وب دریافت نمی‌شود.

## توسعه و آزمون محلی

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py init
.venv/bin/python run.py serve
.venv/bin/python -m unittest discover -s tests -v
```

برای ساخت بستهٔ انتشار از کد بدون دادهٔ فروشگاه:

```sh
.venv/bin/python tools/package_release.py dist/QatYar-Windows.zip
```

جزئیات گسترش در [طرح معماری](docs/architecture.md) آمده است. فونت وزیر با مجوز خودش در `store/static/fonts` قرار دارد.
