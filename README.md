# قطعه‌یار — مدیریت فروشگاه قطعات موبایل

سامانهٔ فارسی برای یک رایانهٔ ویندوزی مرکزی و دسترسی کارکنان از مرورگر شبکه. مبلغ‌های عملیاتی به‌صورت عدد صحیح **ریال** ذخیره می‌شوند و در رابط با جداکنندهٔ هزارگان دیده می‌شوند. پایگاه دادهٔ SQLite هنگام نصب ساخته می‌شود.

## امکانات

- کالا، کد/SKU، جستجوی نام و کد، چند سطح قیمت، موجودی و سابقهٔ تغییرات.
- خرید، فروش، برگشت فروش و خرید از فرم مستقل، ثبت دریافت و پرداخت در حساب صندوق یا بانک انتخابی.
- مشتریان و تأمین‌کنندگان، چک‌ها، درآمد و هزینه، گزارش سود و زیان با بازهٔ تاریخ. همهٔ فهرست‌های عملیاتی صفحه‌های شماره‌دار ۱۰ ردیفی دارند.
- بخش‌های جداگانهٔ تنظیمات برای نام و لوگو، قیمت، حساب‌ها، امنیت، بکاپ و به‌روزرسانی.
- بکاپ روزانه و دستی، بازگردانی روی رایانهٔ جدید و اجرای خودکار برنامه پس از روشن‌شدن ویندوز.
- ورود دادهٔ حسابداری به نصب تازه؛ موجودی و ماندهٔ ابتدای دوره در کار روزانه و فاکتورهای پیشین در فهرست اصلی دیده می‌شوند.

**این مخزن فقط کد و ساختار داده را دارد. هیچ موجودی، فاکتور، چک، کاربر، رمز یا دیتابیس فروشگاه در آن نیست.** نصب تازه با پایگاه دادهٔ خالی شروع می‌شود. برای ادامهٔ کار، بکاپ همین برنامه را بازگردانی کنید یا بستهٔ انتقال دادهٔ حسابداری را در نصب خالی وارد کنید.

## نصب از GitHub روی ویندوز

از صفحهٔ مخزن، نسخهٔ منبع را با `Code → Download ZIP` بگیرید و از حالت فشرده خارج کنید. در پوشهٔ پروژه، PowerShell را با **Run as administrator** باز کنید و اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\install.ps1
```

برای نصب مشتری با دسترسی به نسخه‌های مخزن خصوصی:

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\install.ps1 -GitHubTokenFile 'D:\setup\github-token.txt'
```


نصاب Python 3.12 را از فایل آفلاین همراه بسته، یا در صورت نبود آن از `winget`، آماده می‌کند؛ سپس وابستگی‌ها را از بسته‌های آفلاین یا `pip` می‌گیرد. نصب اینترنتی به اتصال ویندوز به اینترنت نیاز دارد. در اولین نصب، رمز مالک را در همان پنجره تعیین می‌کنید. داده در `C:\ProgramData\MobilePartsShop` و کد در `C:\Program Files\MobilePartsShop` قرار می‌گیرد.

برنامه روی `http://localhost:8080` اجرا می‌شود؛ از دستگاه‌های دیگر شبکه با `http://IP-WINDOWS:8080` باز می‌شود. سرویس در بوت ویندوز بالا می‌آید و میانبر برای همهٔ کاربران در Start Menu، دسکتاپ عمومی و Startup ساخته می‌شود.

## بکاپ و انتقال داده

در پنل مالک، «تنظیمات ← بکاپ» را باز کنید. بکاپ خودکار هر روز ساعت ۲ اجرا می‌شود؛ مسیر پیش‌فرض `C:\ProgramData\MobilePartsShop\backups` است. برای جابجایی، برنامه را روی ویندوز جدید نصب و بکاپ نصب قبلی را با دستور زیر بازگردانی کنید:

```powershell
powershell -ExecutionPolicy Bypass -File 'C:\Program Files\MobilePartsShop\windows\restore.ps1' -BackupFile 'D:\transfer\store-backup.zip'
```

ابزار بازگردانی، برنامه را موقتاً متوقف می‌کند و سلامت فایل بکاپ را بررسی می‌کند. کاربران و رمزهای ذخیره‌شده در بکاپ همراه داده منتقل می‌شوند.

## به‌روزرسانی از GitHub

مالک در «تنظیمات ← به‌روزرسانی» نسخهٔ جدید را از مخزن ثابت برنامه بررسی می‌کند. متن تغییرات Release پیش از دکمهٔ اعمال نمایش داده می‌شود. انتشار باید یک فایل `QatYar-Windows.zip` با اثرانگشت SHA256 در GitHub Releases داشته باشد. نصب خودکار پیش از تغییر کد و دیتابیس بکاپ می‌گیرد. مخزن پیش‌فرض این پروژه `shahabmohamadi/QatYar` و خصوصی است. هر مشتری به توکن خواندن اختصاصی خود برای این مخزن نیاز دارد؛ طبق [مستندات GitHub](https://docs.github.com/en/rest/releases/releases) مجوز `Contents: read` برای بررسی Release کافی است. این مجوز به کد مخزن نیز دسترسی خواندن می‌دهد، بنابراین توکن را فقط برای فرد/نصب مورد اعتماد صادر کنید. هنگام نصب می‌توان فایل توکن را با `-GitHubTokenFile 'D:\setup\github-token.txt'` به نصاب داد؛ نصاب آن را در `C:\ProgramData\MobilePartsShop\github-token.txt` با دسترسی محدود به Administrators و SYSTEM ذخیره می‌کند. توکن از فرم وب دریافت نمی‌شود.

## توسعه و آزمون محلی

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py init
.venv/bin/python run.py serve
.venv/bin/python -m unittest discover -s tests -v
```

برای ساخت بستهٔ انتشار از کد بدون دادهٔ فروشگاه:

```sh
.venv/bin/python tools/package_release.py dist/QatYar-Windows.zip
```

جزئیات گسترش در [طرح معماری](docs/architecture.md) آمده است. فونت وزیر با مجوز خودش در `store/static/fonts` قرار دارد.

API قیمت‌ها (`GET /api/v1/prices`) نیز ۱۰ ردیف در هر درخواست برمی‌گرداند و فیلدهای `page`، `pages`، `total` و `next_page` دارد.

## انتقال از نرم‌افزار حسابداری دیگر

از «تنظیمات ← بکاپ و انتقال داده» قالب استاندارد ZIP را دانلود کنید و خروجی CSV یا مبدل نرم‌افزار قبلی را مطابق آن آماده کنید. اعتبارسنجی مبلغ، موجودی، مانده، فاکتور و تراز سند پیش از ورود انجام می‌شود. راهنمای ستون‌ها: [قالب انتقال اطلاعات حسابداری](docs/accounting-transfer.md). بکاپ بومیِ ناشناخته بدون نمونه و مبدل اختصاصی قابل خواندن نیست.

تقویم شمسی یا میلادی از «تنظیمات ← تاریخ و تقویم» انتخاب می‌شود. نمودار فروش، خرید و سود در پیشخوان بازهٔ تاریخ دارد.
