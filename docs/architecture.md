# معماری قابل گسترش قطعه‌یار

برنامه یک وب‌سرور Python/Flask روی ویندوز مرکزی، دیتابیس SQLite محلی و رابط فارسی مرورگر دارد. فایل‌های داده و رمزها از کد جدا هستند. هر تغییر ساختار دیتابیس یک migration جدید دارد.

| بخش | مسئولیت |
| --- | --- |
| `auth.py`, `users.py` | نشست، کاربران و نقش‌ها |
| `catalog.py`, `search.py` | کالا، قیمت و جستجو |
| `invoices.py`, `returns.py`, `purchase_returns.py` | خرید، فروش، برگشت، موجودی و تسویه |
| `checks.py`, `opening_balances.py` | چک و ماندهٔ افتتاحیه |
| `reports.py` | صندوق، بانک، سود و زیان |
| `settings.py`, `updates.py` | تنظیمات و انتشار نسخه |
| `backup.py`, `db.py`, `migrations/` | بکاپ، اتصال و مهاجرت داده |

مبلغ‌های عملیاتی عدد صحیح ریال هستند. پارسیان نیز مبلغ‌های تاریخی را به ریال نگه می‌دارد. مهاجرت ۰۰۹ مقادیر عملیاتی قدیمی را از تومان به ریال تبدیل می‌کند. پرداخت جدید به یک حساب مالی مشخص وصل می‌شود؛ مانده‌های افتتاحیه و چک‌های تاریخی جداگانه نگهداری می‌شوند. فاکتورهای قطعی تغییر نمی‌کنند و برگشت با سند مستقل ثبت می‌شود.

دیتابیس SQLite با WAL روی همان ویندوز مرکزی قرار دارد؛ فایل آن نباید روی پوشهٔ اشتراکی شبکه باشد. بکاپ با API خود SQLite ساخته و با SHA256 و `integrity_check` بررسی می‌شود. نصب تازه هیچ دادهٔ پارسیان یا فروشگاهی ندارد. برای انتقال داده باید بکاپ نصب قبلی را بازگرداند.

مسیرهای JSON جدید زیر `/api/v1/` قرار می‌گیرند. لایه‌های مستقل برنامه امکان افزودن بارکد، چند شعبه، چاپ فاکتور، دفتر کل دوطرفه و API موبایل را در نسخه‌های بعدی فراهم می‌کنند.
